## ⚠️ Troubleshooting

If the program closes or shows an error, check these common items:

* Your image file must be in a standard format like JPG or PNG.
* If your computer runs out of memory, try to resize your image to a smaller version before you start.
* Make sure you installed all items in the requirements list. If you see a name error, go back to the installation step and run the pip command again.
* Keep your image file in the same folder as the notebook. This helps the program find your files.

## ⚙️ How it works

The software uses a process called deep learning. A neural network looks at millions of images to learn what textures should look like. When you give it your blurry photo, it calculates where the missing pixels should go. It builds a new file based on these patterns. This creates a sharp look that matches your original image. The software handles all the math behind the scenes. You simply provide the input and collect the result.
